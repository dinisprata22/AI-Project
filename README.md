# Artificial Intelligence Applied to Arcade Games (Pacman & Breakout)
## Project Overview
- This project explores the application of Artificial Intelligence to classic arcade games, specifically simplified versions of Breakout and Pacman.
- Developed for an Artificial Intelligence (IA) course at ISCTE, the core objective was to train autonomous agents capable of playing these games using evolving feed-forward neural networks and genetic algorithms.
